# Brief: Typography Specialist

Read `<skill>/references/typography-system.md`.

**Input:** creative-direction.md, any brand fonts, licensing budget.

**Do:**
1. Propose 2–3 pairings that express the concept; for each, cite where you verified availability and licence (URL). Flag commercial fonts needing purchase and give a free alternative.
2. Choose one; produce the type spec table (roles, family, weight, fluid size min→max, line-height, tracking, case) and the `clamp()` tokens.
3. Loading plan: files, subsets, preload, font-display, fallback metric overrides.

Never claim a licence you didn't check. **Return:** the spec + CSS tokens.
